# 欢迎来到 IFBS 大师 Q&A 

请使用此网站共享资源、提出关于论文的问题，并协助解答同学们的疑问。

## 📌 基本要求与规范

* **提问前先浏览：** 添加问题前请先快速使用右上角搜索，避免重复提问。
* **表述清晰具体：** 请务必在问题中标注对应的具体页码、章节或图表编号。
* **记得署名：** 请在你的问题和回答末尾附上姓名缩写（例如：`lzy`）。
* **标注引用来源：** 如引用论文原文或其他外部资料，请务必注明来源。

## 🛠️ 如何提问与回答（操作指南）

本网站基于 GitLab 托管。如需提问或解答，请按照以下步骤操作：

1. 点击网页右上角的 **Edit this page**（或直接进入 GitLab 仓库对应的 `.md` 文件）。
2. 点击 **Web IDE** 或 **Edit** 进入编辑模式。
3. 找到对应 Section 的 Markdown 表格。
4. **提问：** 在表格空行的 `问题` 列使用 HTML 换行符 `<br>` 排版，并在末尾署名（如 `*- LZY*`）。
5. **回答：** 在对应的 `回答与评论` 列填写答案，并在末尾署名。
6. 编辑完成后，点击 **Commit** 提交修改，网站将在 1-2 分钟内自动编译并更新展示。
