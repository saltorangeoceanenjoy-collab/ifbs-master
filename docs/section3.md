# 欢迎来到 IFBS 大师 Q&A 

请使用此网站共享资源、提出关于论文的问题，并协助解答同学们的疑问。

## 📌 基本要求与规范

* **提问前先浏览：** 添加问题前请先快速使用右上角搜索，避免重复提问。
* **表述清晰具体：** 请务必在问题中标注对应的具体页码、章节或图表编号。
* **记得署名：** 请在你的问题和回答末尾附上姓名缩写（例如：`lzy`）。
* **标注引用来源：** 如引用论文原文或其他外部资料，请务必注明来源。
